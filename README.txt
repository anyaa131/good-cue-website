# GOOD CUE. Website

## Dateien in diesem Paket
- `index.html` – Startseite
- `erste-hilfe.html`, `notfallmedizin.html`, `kommunikation-team.html`, `ueber-good-cue.html` – Unterseiten
- `styles.css` – Design und responsives Layout
- `app.js` – mobiles Menü
- `data/site.json` – Textdaten (Grundlage für weitere Pflege)
- `media/` – Logo und separate Bildmotive

## Upload in GitHub
Lade den Inhalt dieses Ordners in das Hauptverzeichnis deines GitHub-Pages-Repositories hoch und behalte die Ordnerstruktur `data/` und `media/` bei. Vorhandene `media/good-cue-logo.png` kannst du durch die hier enthaltene Version ersetzen, wenn du das gleiche Logo verwenden möchtest.

## Vor Veröffentlichung
1. In `index.html` die Platzhalter `DEINE-EMAIL@BEISPIEL.DE` ersetzen.
2. Impressum und Datenschutzerklärung ergänzen bzw. rechtlich prüfen.
3. Inhalte und Kursvoraussetzungen fachlich/rechtlich gegenprüfen.
4. GitHub Pages neu deployen und alle Menü-/Angebotslinks testen.

Die Website verwendet lokale Bilder und ist nicht von einem externen Bilddienst abhängig. Google Fonts werden derzeit über CSS geladen; bei Bedarf kann die Website auch auf lokal eingebundene Schriftdateien umgestellt werden.
